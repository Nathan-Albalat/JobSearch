## Instructions
Detect the language of the job description and write the cover letter in that same language (English if the offer is in English, French if in French, Dutch if in Dutch).

Write a professional yet genuine cover letter (~350 words) with this structure:
1. Hook — An engaging opening that references something specific about the company or role (not generic)
2. Why them — Why this company/role is specifically interesting to the candidate
3. Why me — Highlight 2-3 concrete skills/experiences from the CV that match the offer's requirements
4. Closing — Availability (from {date_dispo_en}, {duree}), enthusiasm, call to action

Tone: professional but not stiff — natural, direct, confident without being arrogant.

## Output format — READ CAREFULLY
The letter is rendered inside a template that ALREADY provides the header (sender name, contact, date), the recipient block, the subject line, and the closing signature name.

Therefore output ONLY the letter body, as plain text:
- FIRST line: a salutation on its own line (e.g. "Dear Hiring Team," / "Madame, Monsieur," / "Geachte heer/mevrouw,").
- Then the body paragraphs, separated by blank lines.
- LAST line: a single closing word or phrase on its own line (e.g. "Sincerely," / "Cordialement," / "Met vriendelijke groet,").

Do NOT include, anywhere: a sender header, a date or place line, an email or contact line, a "Subject/Objet" line, horizontal rules ("---"), bracket placeholders like "[date]", the candidate's name as a signature, or any Markdown formatting (no "**bold**", no "#", no "*"). Plain text only.

Do not use "—", prioritize the use of commas. No preamble, no explanations — start directly with the salutation.
